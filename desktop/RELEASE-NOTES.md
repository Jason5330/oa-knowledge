# OA 知識庫 0.3.0

此版本完成以 Claude Code／Codex MCP 使用為主的本機知識庫流程，另提供選配本機模型連接。

- 獨立本機核心，不再攜帶舊版完整雲端整合套件樹。
- 工作區建立、篩選、重新命名、刪除。
- 八種格式、批次與資料夾匯入、進度、取消、重複內容判斷。
- 文件更新、重建索引、刪除、原始檔匯出。
- 中文語意搜尋、關鍵字加權、頁碼／工作表／投影片來源、長原文分段閱讀。
- 完整備份、保留目前資料的還原方式，以及 0.1 版解析文字遷移入口。
- 八個 MCP 工具、列表分頁、桌面關閉後的讀取。
- 僅接受本機網址的 OpenAI 相容模型介面，預設停用。

2026-09-17 的 runtime `npm audit --omit=dev` 結果：0 個已知漏洞，詳見 reports/runtime-audit.json。這不等於完整安全認證；原始儲存庫中舊版 server／collector 的依賴沒有全部修復，但不包含在 0.3 Windows 執行成品中。

驗證紀錄見 reports；本機模型介面使用模擬服務測試，未對任何實際回答模型做品質或相容性背書。未連接使用者的 Claude Code／Codex 帳號。

尚未提供：回答模型權重、自動啟動模型、OCR、圖片理解、語音、多使用者／SSO、資料加密、自動更新、程式簽章。這些不是主要 MCP 知識庫流程的依賴。


## Excel 結構化處理（0.3）

XLSX 現在保留欄位、型別、原始值、顯示值與公式狀態；預設排除隱藏資料。文件管理中的「Excel 結構」可核對並指定表頭，另可匯出結構化 JSON。新增 inspect_excel、read_excel_rows、aggregate_excel 三個 MCP 工具；詳見 [Excel 評估與實作](EXCEL-DESIGN.md)。舊版 XLSX 在新版啟動時先備份，再從原始檔升級結構與索引。
