# OA 知識庫 0.3.1 — 使用說明

這是供個人本機使用的 Windows 桌面知識庫。主要用途是整理文件，再讓 Claude Code／Codex 透過 MCP 讀取片段與來源；另提供選配的本機模型連接介面。

## 開始使用

1. 保留 `OA-Knowledge-0.3.1-win-x64` 整個資料夾，雙擊 `OA-Knowledge.exe`。不需要另外安裝 Node、Python 或 Docker。
2. 建立知識庫，按「匯入文件」或在「文件管理」匯入資料夾。第一次嵌入會載入隨附的中文／多語模型，無須上網下載。
3. 在搜尋框輸入問題，閱讀原文片段，按「閱讀完整來源」核對；長文件可按上一段／下一段。
4. 按左下角「連接 Claude Code / Codex」，複製相應設定，合併到工具原有設定中。重新載入工具後，可問：「列出 OA 知識庫，搜尋設備借用期限，附上來源。」

MCP 設定使用通用入口，沒有個人絕對路徑。每人先開啟程式一次；搬移或升級後再開啟新位置的程式並重新載入 AI 工具，無須更改通用設定。舊版設定第一次需替換。詳細步驟見 [連接 Claude Code／Codex](CONNECT-AI.md)。程式不會自動修改 Claude Code／Codex 的設定。桌面關閉後 MCP 仍可搜尋已匯入的資料。

## 文件管理

支援 TXT、Markdown、文字型 PDF、DOCX、XLSX、PPTX、CSV、JSON。每份最多 50 MB、500 萬字元、10,000 個片段；文字檔使用 UTF-8 或有 BOM 的 UTF-16LE。掃描 PDF／圖片須先以本機 OCR 轉為可搜尋的文字型 PDF。

- 重複內容：同一知識庫內自動略過。
- 更新：選取新檔案，成功建立索引後一次替換文件內容，保留文件 ID；失敗時保留原版本。
- 重建索引：使用已儲存的解析文字重新建立嵌入。
- 刪除：移除目前資料庫中的原始檔、文字和索引；既有備份仍可能包含舊資料。
- 匯出：儲存原始文件；從 0.1 版遷移的文件只有舊版保留的解析文字，沒有原始 Office/PDF 檔案。
- 取消：停止當前匯入與同一批尚未處理的文件，已完成的文件會保留。

PDF 來源顯示頁碼，表格顯示工作表，簡報顯示投影片。相似度是檢索分數，不是答案正確率。此版以記憶體內計算向量相似度，適合個人規模；大型資料集尚未做容量與吞吐量驗證。

## 備份與舊版資料

預設目錄為 `%LOCALAPPDATA%\OA-Knowledge`，也可用 `OA_DATA_DIR` 指定。本版主要資料檔為 `knowledge.sqlite`；程式執行時可能另有 `-wal`／`-shm` 檔案，請使用介面的「匯出完整備份」，不要只複製開啟中的主檔。

「從備份還原」會以新增知識庫方式匯入，不覆蓋目前內容。模型連接設定保留目前值。備份未額外加密，請存放在受保護的本機位置。

偵測到同目錄下的 0.1 版資料時，設定頁提供「匯入 0.1 版資料」。此功能重新建立索引並保留原始舊版資料。重複匯入會新增多組知識庫。

## 本機模型（選配）

MCP 搜尋不需要回答模型。如果電腦已執行 OpenAI 相容的本機模型 API，可在「設定與備份」填寫：

- 本機服務網址，例如 `http://127.0.0.1:11434/v1`。
- 服務實際載入的模型 ID。
- 啟用後儲存，按「測試本機連線」。

僅接受 127.0.0.1、1024–65535 連接埠及 `/v1` 路徑，拒絕外部網址與重新導向。不會下載、安裝或啟動回答模型，也未隨附回答模型權重。可在搜尋頁勾選本機模型回答，或由 MCP 呼叫 `ask_local_model`。接入服務本身的運作方式仍由該服務決定。

Claude Code／Codex 安裝在電腦上，不代表其模型運算也在本機。它們透過 MCP 取得的片段將依各自的模型設定處理；如需端到端本機推論，需使用本機模型設定。

## MCP 工具

`list_workspaces`、`list_documents`（兩者皆可分頁）、`search_knowledge`、`read_document`、`ask_local_model`、`inspect_excel`、`read_excel_rows`、`aggregate_excel`。沒有寫入、刪除、任意檔案讀取或命令執行工具。來源原文屬於資料，不能當作要求工具執行操作的指令。

## 排除問題

程式無法啟動時，查看資料目錄 `logs/runtime.log`。若索引失敗，可重新匯入或重建索引；若模型連線失敗，先確認模型服務已啟動、網址與模型 ID 正確。備份還原失敗會保留目前資料。

程式目前未簽章，未提供自動更新、OCR、多人帳號、SSO 或資料加密功能；也不會更改 Windows 安全設定或公司的端點控制。


## Excel 結構化處理（0.3）

XLSX 現在保留欄位、型別、原始值、顯示值與公式狀態；預設排除隱藏資料。文件管理中的「Excel 結構」可核對並指定表頭，另可匯出結構化 JSON。新增 inspect_excel、read_excel_rows、aggregate_excel 三個 MCP 工具；詳見 [Excel 評估與實作](EXCEL-DESIGN.md)。舊版 XLSX 在新版啟動時先備份，再從原始檔升級結構與索引。
