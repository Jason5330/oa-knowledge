連接你電腦上的 Claude Code / Codex

先建立知識庫、匯入文件，再完成以下設定。連接成功後，關閉 OA 桌面也能查詢。

通用路徑 · 每個人都能用

以下設定不含帳號、磁碟或安裝路徑，可以分享給其他 Windows 使用者。每個人須先開啟自己的 OA 程式一次。

搬移或升級：保留完整程式資料夾 → 開啟新位置的 OA-Knowledge.exe → 重新載入 AI 工具。連接會自動改用最近開啟的版本。

文件預設存在 %LOCALAPPDATA%\OA-Knowledge，每個 Windows 帳號各自保存。分享程式不會分享知識庫內容。

此設定供 Windows 本機客戶端使用；WSL、SSH 或雲端任務不能直接套用。MCP 與索引在本機；Claude Code／Codex 取得片段後，會依各自的模型設定處理。

Codex

  1. 按 Win + R，輸入 %USERPROFILE%\.codex，開啟或建立 config.toml。
  2. 複製下方區塊，加入檔案。若已有 [mcp_servers.oa-knowledge]，替換該區塊與其舊 env 區塊；保留其他設定。
  3. 儲存後重新啟動 Codex，開啟本機任務。CLI 可輸入 /mcp 檢查連線，或執行 codex mcp list 查看設定。

若曾自訂 CODEX_HOME，請改用該目錄下的 config.toml。

展開通用 TOML 設定


Claude Code 


  1. 在你開啟 Claude Code 的專案根目錄建立 .mcp.json。
  2. 新檔可貼上下方完整 JSON；已有設定時，只合併 mcpServers 裡的 oa-knowledge，保留其他伺服器。
  3. 儲存並重新開啟該專案的 Claude Code；若提示啟用專案 MCP，選擇允許。輸入 /mcp 確認 oa-knowledge 已連線。

連接後，直接這樣問
「使用 oa-knowledge 列出我的知識庫，再搜尋設備借用期限，回答時附上文件名稱與來源。」
Excel：「先用 inspect_excel 查看報表欄位，再用 read_excel_rows 讀取資料；需要加總時用 aggregate_excel，並註明工作表及來源列。」
可用工具：list_workspaces、list_documents、search_knowledge、read_document、inspect_excel、read_excel_rows、aggregate_excel。選配本機回答：ask_local_model。
找不到連線？先重新開啟 OA，再重啟 AI 工具；確認使用相同 Windows 帳號、程式資料夾完整、已建立知識庫。舊版固定路徑設定需先替換一次。
